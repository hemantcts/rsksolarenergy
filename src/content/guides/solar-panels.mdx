export const panelType = (p) => {
  const text = [p.title, p.summary, ...p.features, ...(p.specs?.rows ?? []).flatMap((r) => ('values' in r ? [r.label, ...r.values] : []))].join(' ');
  const bifacial = /bi-?facial/i.test(text) ? ' bifacial' : '';
  if (/topcon/i.test(text)) return `N-type TOPCon${bifacial}`;
  if (/mono|perc/i.test(text)) return `Mono PERC${bifacial}`;
  if (/poly/i.test(text)) return 'Polycrystalline';
  return 'See specification';
};

export const panelWatts = (p) => parseInt(p.title.match(/(\d{2,3})\s*(?:-?\s*watts?\b|wp?\b)/i)?.[1] ?? p.slug.match(/(?:^|-)(\d{2,3})(?:w|wp)(?:-|$)/)?.[1] ?? '0', 10);

## Reading a panel datasheet

- **Maximum power (Pmax),** in watts, measured at standard test conditions: 1000 W/m² of sunlight at a cell temperature of 25 °C. Punjab rooftops in May are far hotter than 25 °C, so real output is lower at midday. Our calculator allows for this.
- **Module efficiency.** The share of sunlight turned into electricity. Higher efficiency means more watts per square foot of roof, which matters when the roof is small.
- **Voc and Isc,** open-circuit voltage and short-circuit current. The installer uses these to match the panel strings to the inverter.
- **Power tolerance.** A positive tolerance means a panel will not produce less than its rating at test conditions.
- **Warranty.** UTL lists a 25-year performance warranty on its panels; the product warranty for defects is separate. Check both on the datasheet of the model you buy.

## The check that decides the subsidy

PM Surya Ghar pays only for systems built with ALMM-listed modules. The inspector checks the model. If it is not on the list, the subsidy is lost and cannot be recovered after installation. Ask for the exact model number on your quote and check it against the current ALMM list before the panels go up.

## Panels alone, or a complete system?

If you are replacing or adding panels to an existing system, match the voltage and current to your inverter or charge controller. If you are starting fresh, buy a matched system: panels, inverter, mounting structure and wiring designed together. It avoids the mismatches that waste generation.
